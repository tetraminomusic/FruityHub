## Проект

Звёздочка закрепления и кнопка обновления выровнены в Windows с помощью иконок в одинаковых полях. Если в проекте есть неотправленные изменения, одновременно выделяются «Отправить» и «Запустить проект».

## Плагины

Кнопка «Скачать…» в таблице снова расположена у левого края. В карточке плагина источник скачивания выбирается из раскрывающегося меню; участники в сети идут первыми.
