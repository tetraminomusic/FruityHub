# FruityHub 0.10.0

Ускорена работа с проектами: разбор больших FLP-файлов требует меньше времени и памяти. Повторные обходы папок сокращены, а основной FLP в корне проекта находится быстрее.

Список проектов и карточки используют отдельный кеш метаданных: для показа названия и параметров проекта больше не требуется полный анализ зависимостей. Полная проверка файлов остаётся доступна там, где она нужна.

При открытии проекта выполняется меньше отдельных команд Git. Ветка, состояние файлов и расхождение с удалённой веткой продолжают проверяться при запросе, поэтому внешние изменения репозитория остаются видны.

По локальным бенчмаркам отдельных операций: анализ большого FLP ускорился примерно в 36 раз, холодный запрос списка из 20 проектов — с 129 до 29 мс, повторное открытие карточки с Git — с 245 до 131 мс. Это измерения отдельных сценариев, а не обещание такого же ускорения всего приложения: результат зависит от проекта, диска и репозитория.
